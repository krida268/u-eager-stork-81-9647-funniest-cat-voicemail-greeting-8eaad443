## Entry

> "You've reached Biscuit. It's 4 a.m. and the bowl is empty. Leave a message — or better, just feed me. Meow."

One line (107 characters): the funniest voicemail greeting a cat would record — a 4 a.m. food demand, because the bowl is empty and the human clearly needs reminding.

## How it works

`main.ts` writes the greeting to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no dependencies, no secrets.
